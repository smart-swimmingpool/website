The Smart Swimming Pool is modular. The **Pool Controller** is the only required part; everything else is optional and can be added once the controller runs.

| Module | Purpose | When to add |
|--------|---------|-------------|
| [Pool Controller](/docs/components/pool-controller/) | Pumps, heating, circulation, web interface | Required — start here |
| [Pool Monitor](/docs/components/pool-monitor/) | Solar-powered wireless temperature display | After the controller is running |
| [Grafana Dashboard](/docs/components/grafana-dashboard/) | Historical charts | When you want long-term data |
| [Water Quality Monitor](/docs/components/water-quality-monitor/) | pH, chlorine and temperature (in development) | Not yet available |

To connect the controller to your smart home, see [Smart Home Integration](/docs/integrations/).
