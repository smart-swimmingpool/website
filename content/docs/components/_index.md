The Smart Swimming Pool is modular. The **Pool Controller** is the only required part; everything else is optional and can be added once the controller runs.

| Module | Purpose | When to add | Difficulty | Cost |
|--------|---------|-------------|------------|------|
| [Pool Controller](/docs/components/pool-controller/) | Pumps, heating, circulation, web interface | Required — start here | ⭐⭐ | ~35–55 € |
| [Pool Monitor](/docs/components/pool-monitor/) | Solar-powered wireless temperature display | After the controller is running | ⭐⭐ | ~45–70 € |
| [Grafana Dashboard](/docs/components/grafana-dashboard/) | Historical charts | When you want long-term data | ⭐ | Free |
| [Water Quality Monitor](/docs/components/water-quality-monitor/) | pH, chlorine and temperature (in development) | Not yet available | ⭐⭐⭐ | tbd |

To connect the controller to your smart home, see [Smart Home Integration](/docs/integrations/).
